# PEU & AR-DFL ablations — full metric tables

Source: `arch_best/arch_luggage_eval/runs_peu__test_full_dataset.json`,
`runs_lossv2__test_full_dataset.json`. Split `test_full_dataset`. All values ×100.

> **Read the caveats before the numbers.**
>
> 1. **`peu_anchor2` is 18.36 pt below `peu_anchor` on an identical nominal config.**
>    Not seed noise. Until that is explained, treat every row as provisional.
> 2. **The two ablations are not comparable.** PEU ran at `topk=10, α=0.5, β=6.0`;
>    `runs_lossv2` at `topk=12, α=0.6, β=5.0`.
> 3. **`runs_lossv2` has no stock baseline.** Its anchor `ardfl_h15` is itself a
>    mechanism (AR-DFL, h-weight 1.5), so `lba_s10` etc. are measured against AR-DFL.
> 4. **The saved configs do not record the mechanism.** Every entry in a file has an
>    identical `config` dict (`use_satal`, `satal_*`, `tal_*` only) — no `peu_*`,
>    `lba_*`, `ardfl_*`. Only the run name identifies what ran.
> 5. Project reproducibility tolerance is **±0.35** (`loss2.py:7-8`). Every non-collapsed
>    delta below is inside it.
