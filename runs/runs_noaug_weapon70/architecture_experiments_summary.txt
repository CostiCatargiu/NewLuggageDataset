# ---- ARCHITECTURE NOTES ----
#
# Key design choices in standard YOLOv12s:
#
# BACKBONE:
#   Layer 2 (P2):  C3k2, 2 reps, no attention — early feature extraction
#   Layer 4 (P3):  C3k2, 2 reps, no attention — small object features (80x80)
#   Layer 6 (P4):  A2C2f, 4 reps, attention=True, 4 heads — medium features (40x40)
#   Layer 8 (P5):  A2C2f, 4 reps, attention=True, 1 head — large features (20x20)
#
# HEAD (FPN + PAN):
#   Layer 11 (P4 top-down):   A2C2f, 2 reps, attention=False
#   Layer 14 (P3 head):       A2C2f, 2 reps, attention=False  <-- small object detection
#   Layer 17 (P4 bottom-up):  A2C2f, 2 reps, attention=False
#   Layer 20 (P5 head):       C3k2, 2 reps, shortcut=True     <-- ONLY layer using C3k2 in head
#
# OBSERVATIONS:
#   - Attention is ONLY in backbone P4/P5 (layers 6, 8)
#   - HEAD layers have NO attention (all False or C3k2)
#   - P3 (small objects) has LEAST processing: C3k2 backbone + A2C2f head (no attention)
#   - P5 head is the ONLY head layer using C3k2 instead of A2C2f
#   - With 's' scale: depth=0.5, width=0.5, max_channels=1024
